# Deeksha Ct - E-Portfolio

This is a premium, modern, and highly responsive personal e-portfolio built for **Deeksha Ct**, a Computer Science and Engineering student at REVA University (class of 2025) based in Bengaluru, India.

## ✨ Features

- **Double-Theme System**: Smooth, animated transitions between a refined default Dark Theme and a clean Light Theme. The choice is persisted in `localStorage`.
- **Dynamic Hero Section**: Features an interactive dynamic typing effect showing different roles, glowing visual orbits representing development graphics, and floating tech badges.
- **Academic Timeline**: Highlights coursework, self-learning milestones, and graduation goals at REVA University.
- **Toolbox Skill Tabs**: Categorized progress indicators for Frontend Development, Backend Languages (Java, Python, SQL), and Tools (Git, VS Code, Figma).
- **Project Grid Filter**: Dynamic categories displaying featured projects, including:
  - **AIFI - AI-Powered Financial Insights Dashboard**: An interactive budget tracker and prediction system.
  - **E-Portfolio**: The source code of this modern web experience.
  - **Command Line Study Organizer**: An OOP-based study helper built with Python.
- **Interactive Contact Card & Form**: Floating inputs with custom focus glows and a simulated form submission workflow displaying a checkmark confirmation card.
- **Performance Optimized**: Zero external framework dependencies, lightweight SVGs instead of bulky images, and smooth animations using native Intersection Observers.

## 🛠️ Tech Stack

- **Structure**: Semantic HTML5
- **Styling**: Modern CSS3 Custom Properties (variables, Flexbox, Grid, keyframe animations, glassmorphism)
- **Logic**: Vanilla ES6+ JavaScript
- **Icons**: Lucide Icons

## 🚀 How to Run Locally

You can launch and view this static portfolio website using any of the following methods:

### Method 1: Direct File Opening
Double-click on [index.html](file:///c:/Users/ctcha/AIFI/AIFI/index.html) or drag it into any modern web browser.

### Method 2: Python Local Server (Recommended)
If you have Python installed:
1. Open terminal inside the project directory.
2. Run:
   ```bash
   python -m http.server 3000
   ```
3. Open browser and go to: `http://localhost:3000`

### Method 3: Node.js Local Server
If you have Node/npm installed:
1. Open terminal inside the project directory.
2. Run:
   ```bash
   npx http-server -p 3000
   ```
3. Open browser and go to: `http://localhost:3000`
